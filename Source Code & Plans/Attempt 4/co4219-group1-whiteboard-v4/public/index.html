CO4219 ~ Distributed Whiteboard

This is a simple distributed whiteboard application built using Node.js, Socket.io, and Redis, hosted with Google Cloud. Multiple users can modify the whiteboard simultaneously, and changes are synchronised in real time. It includes basic drawing capabilities, like free-form drawing, lines, shapes, and the ability to clear the whiteboard.

For more information on how to use the whiteboard, please see the "Help" option below.

Connected Users: 999
Using the Whiteboard
  • Select a tool from the toolbar to start drawing
  • Click and drag on the canvas to draw shapes or erase
  • Use the colour picker to change the drawing colour.
  • Adjust the brush width using the width input
  • Click the clear button to erase the entire canvas
